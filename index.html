안전보건 입찰 평가표

업체별 D-Safe점수와 입찰금액을 입력하면 나머지 항목이 자동 계산됩니다.

참여업체 업체명 업체수준 D-Safe점수 환산 안전Hurdle
(가감점)		 소계 입찰금액 가격점수 안전보건점수 종합평가결과 입찰순위 D-safe
자동계산점수		 비고

계산 기준

  • 입력받는 값 : 업체별 D-Safe점수, 입찰금액 (입찰금액이 비어 있으면 미참여 처리)
  • D-Safe점수 입력이 없는 참여업체는 업체수준에 따라 자동 계산
    • 업체수준 상 : 입력된 D-Safe점수 중 최고점
    • 업체수준 중 : 입력된 D-Safe점수들의 평균점
    • 업체수준 하 : 입력된 D-Safe점수들의 최하점
    • 단, 입찰 미참여 업체의 D-Safe점수는 자동 계산 시 제외
    • 자동 계산된 점수는 소수 첫째 자리에서 반올림한 값으로 환산·소계 등 이후 계산에 사용 (예: 평균 78.63 → 78.6)
  • 환산 = 20 × ( D-Safe점수 ÷ 100 )
  • 소계 = 환산 + 안전Hurdle(가감점)
  • 가격점수 = 80 × 최저 입찰액 ÷ 해당업체 입찰액
  • 안전보건점수 = 20 × ( D-Safe점수 ÷ 100 ) + 안전Hurdle점수
  • 종합평가결과 = 가격점수 + 안전보건점수 → 높은 순으로 입찰순위 부여
  • D-safe 자동계산점수 : D-Safe점수를 입력하지 않아 업체수준으로 자동 계산된 경우 그 점수를 표시
  • 비고 : 자유롭게 입력 가능, 최저 입찰금액 업체에는 최저가 업체, 입찰순위 1위 업체에는 ★최적입찰선정업체가 자동 표시
