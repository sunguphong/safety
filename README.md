# 안전보건 입찰 평가표

업체별 D-Safe점수와 입찰금액을 입력하면 가격점수·안전보건점수·종합평가결과·입찰순위를 자동 계산합니다.

- **웹사이트:** https://sunguphong.github.io/safety/
  - 서버 없이 동작하며, 입력한 데이터는 **접속한 브라우저에만** 저장됩니다.
- **공동 편집(서버) 모드:** `node server.js` 로 실행하면 같은 데이터를 여러 명이 함께 편집합니다.
  - 인터넷 공개: `start-public.ps1`(ngrok) 또는 `start-public-cloudflare.ps1` — 실행 시 비밀번호를 입력받습니다.
