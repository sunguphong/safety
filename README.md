# 안전보건 입찰 평가표

업체별 D-Safe점수와 입찰금액을 입력하면 가격점수·안전보건점수·종합평가결과·입찰순위를 자동 계산합니다.

- **웹사이트:** https://sunguphong.github.io/safety/
  - 서버 없이 동작하며, 입력한 데이터는 **접속한 브라우저에만** 저장됩니다.
- **공동 편집(서버) 모드:** `node server.js` 로 실행하면 같은 데이터를 여러 명이 함께 편집합니다.
  - 인터넷 공개: `start-public.ps1`(ngrok) 또는 `start-public-cloudflare.ps1` — 실행 시 비밀번호를 입력받습니다.

## 주요 기능

- **이미지에서 불러오기:** `🖼 이미지에서 불러오기` 버튼, 캡처 화면 **Ctrl+V** 붙여넣기, 이미지 파일 끌어다 놓기로 표 이미지를 읽어 업체 데이터를 등록합니다.
  - 글자 인식(OCR, Tesseract.js)은 브라우저 안에서 처리되며 이미지는 외부로 전송되지 않습니다. 처음 사용할 때 인식 엔진과 한글 데이터를 인터넷에서 한 번 내려받습니다.
  - 인식 결과는 미리보기 표에서 확인·수정한 뒤 **기존 표에 추가** 또는 **표 전체 교체**로 반영합니다. 화면 캡처처럼 선명한 이미지일수록 정확합니다.
- **D-safe 자동계산점수:** D-Safe점수를 입력하지 않은 업체는 업체수준(상=최고점 / 중=평균점 / 하=최하점)으로 계산된 점수를 마지막 쪽 열에 표시합니다. 자동 계산 점수는 소수 첫째 자리에서 반올림한 값으로 이후 계산에 사용합니다.
- **비고:** 자유롭게 메모를 입력할 수 있고, 최저 입찰금액 업체에는 **최저가 업체**가 자동 표시됩니다(참여업체 2곳 이상일 때).
- **현재 상태 저장:** 지금 표를 이름 붙여 저장해 두고 언제든 다시 불러올 수 있습니다.
